# GOLF GUTS 関東ゴルフコースガイド

GitHub Pages用の静的サイト。2026年10月25日時点のSites v38から書き出しました。

## 公開
公開済みです。更新は最新mainを基準に差分だけを反映してください。古いZIPや古いdata.jsの上書きは禁止です。確認済み情報の自動検証・公開手順は [MAINTENANCE.md](MAINTENANCE.md) を参照してください。

## 含まれる機能
500コース、10カテゴリ、都県別検索、4つの質問、おすすめ4コースの比較、お気に入り。トップとカテゴリの既存画像も同梱。

## この版で外した機能
楽天APIによるコース写真の取得はサーバー処理が必要なため含みません。APIキーも含みません。GUTS DESKの閲覧計測は元サイト専用のため含みません。GitHub側の閲覧数は元サイトの管理画面へ送信されません。

## 移行時の注意
URLが変わるため、元サイトのお気に入りは引き継がれません。元の公開サイトは変更していません。掲載情報の確認日は元データのままです。この書き出しで全コースの情報を再調査したものではありません。
